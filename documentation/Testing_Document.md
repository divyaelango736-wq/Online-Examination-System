
# SOFTWARE TESTING DOCUMENT

## Project: Online Examination System

## 1. Introduction
Testing is performed to verify that the Online Examination System works correctly and meets its requirements.

## 2. Types of Testing

### Unit Testing
Testing individual modules such as registration, exam creation and result calculation.

### Integration Testing
Testing the connection between Java, PostgreSQL and Python.

### System Testing
Testing the complete Online Examination System.

### Validation Testing
Checking whether the system meets user requirements.
