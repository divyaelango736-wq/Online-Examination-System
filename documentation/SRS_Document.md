
# SOFTWARE REQUIREMENTS SPECIFICATION

## Project Title
Online Examination System

## 1. Introduction
The Online Examination System is a web-based application used to conduct examinations, manage students, and analyze examination results.

## 2. Objectives
- Provide online examinations.
- Manage student details.
- Store examination questions and results.
- Generate student performance reports.
- Analyze results using Python.

## 3. Functional Requirements
1. Student registration.
2. Admin exam creation.
3. Question management.
4. Online examination.
5. Automatic mark calculation.
6. Result viewing.
7. Student performance analysis.

## 4. Non-Functional Requirements
- User-friendly interface.
- Secure password storage.
- Reliable database connection.
- Accurate result processing.
- Maintainable software.

## 5. Hardware Requirements
- Computer or laptop.
- Minimum 4 GB RAM.
- Keyboard and mouse.
- Internet browser.

## 6. Software Requirements
- Operating System: Windows
- Programming Language: Java
- Database: PostgreSQL
- Frontend: HTML, CSS, JavaScript
- Data Analysis: Python
- IDE: Visual Studio Code

## 7. Technologies Used
- Java for backend development.
- PostgreSQL for database management.
- Python for performance analysis.
- HTML, CSS and JavaScript for frontend.

## 8. Expected Outcome
The system provides online examinations, stores student results, and generates performance analysis reports.
