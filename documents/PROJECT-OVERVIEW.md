# Project Overview

## Title
Online Examination Management and Student Performance Analysis System

## Scenario
Scenario 28 — Register Number 28.

## Problem
Manual handling of internal assessments, model examinations, registrations, marks and results can cause calculation errors, make participation tracking difficult, and delay identifying students who need academic support.

## Proposed solution
A web-based application to manage student records, examination schedules, questions, registrations, responses and results. Java handles application logic, PostgreSQL stores records, and Python retrieves result data for cleaning, analysis and visualization.

## Main modules
1. Student management
2. Examination management
3. Question management
4. Examination registration
5. Online examination and response submission
6. Automatic objective evaluation
7. Result calculation
8. Reports and performance analysis

## Scope of first release
The first release focuses on MCQ examinations and basic performance reporting. Descriptive answers and advanced analytics can be added after the core workflow works.
